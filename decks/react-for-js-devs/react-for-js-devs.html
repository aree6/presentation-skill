Four Rules Keep Hooks Honest

React pairs each call by order, so order is the contract.

Call hooks at the top, every renderNo branch skips a call, so the order never shifts.Always
Call hooks only from components or hooksA plain helper cannot borrow this memory.Always
Never call a hook inside a loop or a branchA skipped call shifts every call below it.Never
Never read state to write the same state backDerive it during render, or store the cause.Never
Same order, every render, or React pairs the wrong memory.
